## Embedded font and native material

Avalonia.Fonts.Inter includes Inter 3.019. Exact bytes of all six fonts from the pinned
Avalonia source revision occur in all three NuGet resource assemblies. The font metadata names
SIL Open Font License 1.1 and the Inter Project Authors. The [Inter copyright and full OFL](third_party/licenses/Inter-OFL-1.1.txt)
are included separately from Avalonia's MIT license. The fonts are distributed unmodified.

The complete Avalonia, SkiaSharp/HarfBuzzSharp and ANGLE notices are retained, including
their embedded-component attributions. Some upstream notice collections conservatively
describe components beyond those used on a particular platform; their text is not trimmed.

## .NET app host and external system components

The archive includes a generated native .NET app host. The [MIT license](third_party/licenses/dotnet-LICENSE.txt)
and [third-party notices supplied by the reviewed Ubuntu .NET SDK distribution](third_party/licenses/dotnet-ThirdPartyNotices.txt)
are included. The .NET shared runtime itself is not bundled; users install .NET 10 separately.
The checked packaging SDK is 10.0.114 (runtime distribution 10.0.14); a different SDK needs
its supplied notices reviewed before packaging.

BlueZ, Linux kernel drivers, system libraries and ViGEmBus are separately installed,
not bundled. The MIT-licensed ViGEm client package is distinct from the driver.

## Development tooling

Playwright 1.64.1 (`@playwright/test`, `playwright`, `playwright-core`) is used only for
development and tests. Its [Apache-2.0 license](third_party/licenses/Playwright-LICENSE.txt)
and [NOTICE](third_party/licenses/Playwright-NOTICE.txt) are included for reference.
Node modules, downloaded browsers and .NET test dependencies are not shipped in the app
archive. Their own package licenses apply when those tools are installed separately.

## Provenance and update checks

[third_party/manifest.json](third_party/manifest.json) records exact NuGet versions and
package hashes, npm lock integrity values, notice SHA-256 values and upstream/package
provenance. Avalonia/Tmds/ViGEm notices are pinned to package source revisions. MicroCom
declares MIT but omits a source revision; its license is taken from the 2021 commit that
introduced the unchanged upstream LICENSE. SDK notices come from the installed vendor
distribution rather than an assumed upstream tag.

`scripts/bundle-notices.py` runs offline during packaging. It rejects unknown dependency
versions/hashes or dependency bytes, missing or altered notice texts, unreviewed SDKs, and changed npm
dependencies. Review upstream terms and update the manifest and full texts together
when changing dependencies. Links and SPDX labels alone are not the notice bundle.
